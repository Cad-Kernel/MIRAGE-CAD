# Evidence index

Every imported source is classified in `catalog.jsonl`: included anonymous copy, hash-only checkpoint,
separate corpus, third-party reference, redundant archive, or private editorial material. No scientific
outcome is silently dropped to improve a result. `bundle_manifest.jsonl` verifies the distributed bytes;
`provenance.jsonl` records original hashes separately. Old manifests/filenames may identify original
bytes and must not be mistaken for hashes of the transformed copies.

| Directory | Contents and reading order |
|---|---|
| `review_01_interface_replications/` | Frozen recipe and original seed/result records; read the CPU provenance/token audit before interpreting the comparison. |
| `review_02_construction_disjoint/` | Frozen split IDs/manifest, NN and retrained MIRAGE raw metrics, protocol and limitations. |
| `review_03_fullstack_replications/` | Four per-seed paired-case JSONLs, summaries and equal-weight seed aggregate. |
| `review_04_exposure_policy/` | Frozen manifests, actual training-step records, packing amendment, eight evaluation groups and paired raw rows. |
| `review_05_four_pathway_gallery/` | Candidate IDs, actual inputs/plans/code, historical result rows, two-view assets and raw archive objects. |
| `review_06_fusion360/` | 400-ID correspondence, three-method taxonomy, raw results, gallery, camera policies and transforms. |
| `cpu_audits/` | Source-bound Review 01 audit, native raw-result copies, result arithmetic, parameter examples and external-method metadata. |

Historical Markdown records are retained with an English archival banner. New README files are
English navigation guides. A historical CLOSED label concerns execution of that package; it does not
override later provenance limits or certify causal control. Main-text case candidates remain candidates
until actually reviewed and placed in the manuscript.

Parameter examples: `cpu_audits/parameter_visuals_v1/index.html`.
Four-pathway examples: `review_05_four_pathway_gallery/rendering/cpu_v1/index.html`.
Fusion examples: `review_06_fusion360/main_review_v1/index.html`.

Missing individual metrics stay unavailable; measured zero stays zero. Failure-as-zero is used only
for an explicitly defined unconditional metric, not to fabricate individual geometric measurements.
