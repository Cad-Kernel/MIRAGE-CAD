# Scientific and reproduction limits

- The four-pathway setting uses one active modality and unequal information budgets; it is not fusion.
- The STEP branch effectively uses 50 global statistics, not per-face/edge topology encoding.
- Review 01 is not a strict matched interface experiment. Warm starts, restoration rules, mixed-step
  available artifacts and reconstructed target truncation remain; historical prediction-to-weight-byte
  binding is not established. Opposing confounds are not assumed to cancel. No equivalence claim follows.
- Four full-stack B0/B2 seed pairs are available, but all other conditions/modalities were not replicated.
  Query-level paired tests do not establish training-run robustness; four consistent seed signs give
  two-sided exact p=0.125. B2 syntax and conditional mean CD are worse despite favorable coverage/medians.
- Construction-disjoint testing holds out four single-operation signatures within the same corpus.
- The exposure-policy control uses one paired seed and changes cumulative exposure as well as order.
- The historical gallery uses repaired deployed B2. Current CPU re-exports are not recovered historical
  geometry bytes and do not change original metrics or prove semantic correctness.
- Parameter responsiveness is conditional on 74/100 valid programs: 1,608 edits, 1,321 changed, 267 no
  change, 16 change-unknown and four failures. Mean numeric-argument reachability is about 29.3%.
  No plan-versus-code semantic editing or user benefit has been established.
- The lexical program-operation counter can count names/comments. Its absolute level is not semantic
  operation accuracy; unaffected rankings are not assumed without a specific verified analysis.
- External CAD-Recode performance remains stronger. Different normalization/scoreability conditions,
  null IoU versus measured zero, and missing historical revision binding must remain explicit.
- Weight metadata/HEAD and a cross-benchmark source table are not new common-protocol experiments.
- Source/static/model-free checks do not provide the absent native runtime, corpus, model weights,
  final figure adoption, complete environment reproduction or verified anonymous hosting.
